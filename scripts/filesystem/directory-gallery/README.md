# Directory gallery

Generate a modern, dark static HTML gallery from a two-level directory tree:

```text
INPUT/
├── Creator A/
│   ├── portrait.jpg
│   ├── Project One/
│   │   └── cover.jpg
│   └── Project Two/
│       └── cover.png
└── Creator B/
    └── Another Project/
```

Every immediate child directory of the input is a creator. Every immediate
child directory of a creator is a project. Files and deeper directories do not
otherwise affect discovery.

## Requirements

- Python 3.9 or later
- Pillow 10 or later

Install the project in a virtual environment from this directory:

```bash
python3 -m venv .venv
.venv/bin/pip install -e .
```

## Usage

```bash
directory-gallery INPUT_FOLDER OUTPUT_FOLDER
```

The output folder contains `index.html`, its CSS and JavaScript, and the cached
thumbnails used by the page. Open `index.html` in a browser. Creator names and
portraits link to creator directories; project names and covers link to project
directories.

Use repeatable exclusions for utility directories or unwanted projects:

```bash
directory-gallery INPUT_FOLDER OUTPUT_FOLDER \
  --exclude meta \
  --exclude "Creator A/Drafts" \
  --exclude "Creator B/*"
```

Patterns are case-sensitive and apply to logical `CREATOR/PROJECT` paths. A
pattern without `/` matches project names. `*`, `?`, and character classes are
supported within a component. `**` and backslashes are rejected.

Use `--title` to replace the input directory name in the page heading:

```bash
directory-gallery INPUT_FOLDER OUTPUT_FOLDER --title "My collection"
```

## Artwork

Only exact lowercase role names are recognized directly in their corresponding
directories:

1. `portrait.jpg`, `portrait.jpeg`, then `portrait.png` for creators
2. `cover.jpg`, `cover.jpeg`, then `cover.png` for projects

The first existing file in that order is used. Multiple candidates produce a
warning. Missing or unreadable artwork receives a placeholder.

Generated thumbnails preserve the source aspect ratio and are stored under
`OUTPUT_FOLDER/thumbnails`. The cache is updated incrementally and stale files
previously generated by this tool are pruned. Source directories are never
modified.

The output must be dedicated to Directory Gallery. An existing non-empty folder
without its manifest is rejected, and input and output trees may not overlap.

